About SMS transaction detection

Sanspend can detect transactions from bank/UPI SMS text that you paste or import into the app. No website or browser — including this one — can silently read your phone's message inbox in the background; that would require a native app with special system permission, which this app does not have. Nothing is ever scanned automatically behind the scenes.

Whenever you do paste or import SMS text, it's parsed entirely on this device. It is never sent anywhere or included in any automatic backup — the only way SMS text would leave this device is if you personally export your data.
